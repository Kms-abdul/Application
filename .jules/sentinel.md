## 2024-05-18 - Prevent SQL Injection from f-strings in dynamically constructed raw SQL query
**Vulnerability:** An f-string `conditions.append(f"(MONTH(date) = {m['month']} AND YEAR(date) = {m['year']})")` was used to inject integer parameters into the `attendance_query` inside `erp-backend/routes/report_card_routes.py`. F-strings are fundamentally risky when generating raw SQL queries, as they bypass standard parameterized query constraints. If an external or database-level input had arbitrary string input, this could result in a SQL Injection vulnerability.
**Learning:** `mysql.connector` with variable conditions constructed dynamically in a loop should still leverage parameterization instead of Python string formatting.
**Prevention:** Construct the query string with `%s` placeholders, and dynamically `extend` those parameter values to an explicit list (`att_params.extend([m['month'], m['year']])`). Pass the finalized array as a tuple during `cursor.execute(query, tuple(params))`.
